# bin-builder

![cover](/tools/bin-builder-baner.webp)


Когда парк серверов это зоопарк из разных ОС и их версий, интеграция Ansible ролей превращается в боль. 
Поэтому был создан этот репозиторий — коллекция рецептов сборки бинарников,
в которые по возможности включены все зависимости для максимальной совместимости.
